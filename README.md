# Task Tracker ✅

A simple **vanilla JavaScript Task Tracker** with CRUD functionality, category filters, overdue highlighting, and completion toggles. Built with **HTML, CSS, and JS only**—no frameworks.

---

## ✨ Features
- Add, edit, delete tasks
- Categories (Work, Personal, etc.)
- Filter tasks by category or completion status
- Highlight overdue tasks in red
- Completion toggle with checkbox ✅
- LocalStorage persistence
- Polished UI with animations and icons
